# Project Statement

## 1. Problem Statement

Managing student attendance manually can require repeated record keeping and calculations. It can become difficult to maintain student information, record attendance, calculate attendance percentages, and identify students who meet the required attendance level.

The **Student Attendance Management System** is developed as a simple Python-based console application to organise these basic attendance management tasks in one system.

The application provides separate functions for managing students, recording attendance, and analysing attendance information.

## 2. Scope of the Project

The scope of the project includes the basic management and analysis of student attendance through a console-based Python application.

The project covers:

- Adding student records.
- Removing student records.
- Searching for students.
- Viewing registered students.
- Recording Present and Absent attendance.
- Viewing attendance records.
- Calculating attendance percentages.
- Checking the 75% attendance eligibility requirement.
- Finding the highest attendance.
- Finding the lowest attendance.

The project is intended for basic attendance management and does not currently include a database, graphical user interface, online access, or permanent data storage.

## 3. Target Users

The intended users of the project are:

- **Teachers** who need a simple way to record and check student attendance.
- **Students** who want to understand their attendance status.
- **Educational project users** who want to practise basic Python programming concepts.
- **Small classroom environments** where a simple console-based attendance system is sufficient.

## 4. High-Level Features

### Student Management
The system provides basic operations for adding, removing, searching, and viewing student records.

### Attendance Management
The system allows attendance to be recorded as Present or Absent and provides an option to view the recorded attendance.

### Attendance Analysis
The system calculates attendance percentages and checks whether students meet the 75% attendance requirement.

### Attendance Comparison
The system can identify the student with the highest attendance and the student with the lowest attendance.

### Menu-Based Operation
The application uses a menu-driven console interface to make the different functions accessible from the main program.

## 5. Project Modules

The project is organised into separate modules:

- `main.py` — controls the main application and menus.
- `stu_manage.py` — manages student information.
- `attendance.py` — manages attendance records.
- `att_analyse.py` — performs attendance calculations and analysis.

## 6. Expected Outcome

The expected outcome of the project is a working console-based application that provides a simple way to manage student records and attendance while reducing the need for manual attendance calculations.
